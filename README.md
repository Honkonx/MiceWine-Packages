# MiceWine-Packages/

Sistema de build de los paquetes nativos que usa MiceWine (Box64 en varias versiones, Wine, Vulkan, GStreamer, librerías X11, etc.), empaquetados en formato `.rat`. Se compila cruzado para Android vía chroot Arch Linux + NDK, con CI real en `.github/workflows/build.yml` (runner `ubuntu-latest`).

Fork del usuario: https://github.com/Honkonx/MiceWine-Packages

Ver `index.md` para el listado de rutas.
